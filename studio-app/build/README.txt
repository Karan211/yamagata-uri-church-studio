야마가타우리교회 스튜디오 1.3.0
================================
배경 영상 만들기 · 성경 자막 · 한국어⇄일본어 동시통역 · 방송(장면 전환, 녹화, 유튜브 송출)

■ 맥 (Mac)
  1. 「야마가타우리교회 스튜디오.app」 을 「응용 프로그램」 폴더로 옮깁니다.
  2. 처음 열 때는 앱을 오른쪽 클릭 →「열기」를 누릅니다.
     "손상되었다" 거나 "열 수 없다" 고 나오면 터미널에서 아래 한 줄을 실행한 뒤 다시 엽니다.
        xattr -cr "/Applications/야마가타우리교회 스튜디오.app"
  - 애플 칩(M1 이후) 맥은 mac-arm64, 인텔 맥은 mac-intel 파일을 쓰세요.

■ 윈도우 (Windows 10/11, 64비트)
  1. 압축을 풀고 폴더 안의 「야마가타우리교회 스튜디오.exe」 를 실행합니다.
  2. "Windows의 PC 보호" 창이 나오면 「추가 정보」→「실행」을 누릅니다.

■ 함께 필요한 것
  - Google Chrome : 동시통역(음성 인식)은 Chrome 에서 열립니다.
  - ffmpeg : 유튜브 실시간 송출과 녹화 MP4 정리에 씁니다. 없어도 나머지는 동작합니다.
        맥     : brew install ffmpeg
        윈도우 : winget install ffmpeg   (설치 후 앱을 다시 켜기)
  - 인터넷 : 동시통역과 유튜브 송출에 필요합니다.

■ 알아 둘 점
  - 정식 서명(개발자 인증)이 없는 프로그램이라 처음 실행할 때 위와 같은 경고가 나옵니다.
  - 녹화 파일은 「동영상」(Movies / Videos) 폴더에 저장됩니다.
